Cron Schedule (Recommended)

Add to crontab for weekly automated runs:

# Monday 6 AM UTC — full pipeline
0 6 * * 1 cd /path/to/project && ANTHROPIC_API_KEY=your-key YOUTUBE_API_KEY=your-key \
    python run_social_listening.py run >> logs/social_listening.log 2>&1

# Daily 8 AM UTC — collect only (lightweight, no AI cost)
0 8 * * * cd /path/to/project && \
    python run_social_listening.py collect --sources reddit,rss >> logs/collect.log 2>&1
